# Student Grade Calculator

## About the Project

Student Grade Calculator is a simple C program that calculates a student's total marks, percentage, grade, and result based on marks obtained in five subjects.

This project demonstrates basic C programming concepts such as variables, user input, arithmetic operations, conditional statements, and formatted output.

## Features

* Accepts the student's name
* Accepts marks for five subjects
* Calculates total marks
* Calculates percentage
* Assigns a grade based on percentage
* Displays Pass or Fail result

## Subjects

The program accepts marks for:

* C
* C++
* Mathematics
* Physics
* English

## Grading System

| Percentage   | Grade |
| ------------ | ----- |
| 90 and above | A     |
| 80–89        | B     |
| 70–79        | C     |
| 60–69        | D     |
| 50–59        | E     |
| Below 50     | F     |

## How to Run

Compile the program using:

```bash
gcc student_grade.c -o student_grade.exe
```

Run the program using:

```bash
.\student_grade.exe
```
